    What happens when you search

    1. Understand (1 Claude call, quick). Detects language and dialect, routes rulings or off-topic requests, and writes an MSA rewrite plus two paraphrases in Classical Quranic vocabulary. The raw query is kept for the ranking step.
    2. Retrieve (in your browser, no model). BM25 over two fields for all 6,236 ayat: the ayah text and Tafsir al-Muyassar, with Arabic normalization that matches Uthmani spelling to modern spelling. Each rewrite is searched in each field and the lists are merged with Reciprocal Rank Fusion; the top 40 go forward. Keyword search never runs on the raw dialect text.
    3. Rank (1 Claude call). Claude reads the raw query, the rewrite and each candidate with its tafsir, and returns only ayah IDs with a grade (direct, implicit or story, related) and a one-line reason, or “no relevant ayah”.
    4. Guard. IDs that were not among the candidates are dropped. Each reason is checked against the whole Quran for any run of 5 consecutive words; a reason that quotes the Quran is withheld.
    5. Render. Ayat are shown by ID from the Tanzil Uthmani text, never from model output. Each card links to the full tafsir it cites.

    Differences from the full pipeline 1 design: no dense embedding search yet (no embedding API is reachable from this demo), and no Franco-Arabic transliteration step beyond what the understanding call does. Both are planned additions.
